# Автоматическая установка тестового DXVK перед игрой

Этот пакет не запрещает WeHavePhones восстанавливать библиотеки. Он устанавливает
нашу проверенную пару ПОСЛЕ запуска контейнера и ПЕРЕД запуском игры.
Используйте только отдельный тестовый контейнер и тестовую копию WoW.
main, APK WeHavePhones и рабочий контейнер изменять не требуется.

## Один раз
1. Распакуйте ВЕСЬ ZIP в отдельную постоянную папку на D:, например D:\WoW-DXVK-test.
   Сохраните структуру payload, stock, logs и файл dxvk-test.exe рядом с BAT-файлами.
2. В тестовом контейнере должна быть папка C:\DXVK-backup с ОБЕИМИ исходными DLL.
   Она создана при предыдущем тесте. Утилита проверит их SHA-256 и не перезапишет.
   Если папки нет, создайте её в тестовом контейнере и скопируйте туда обе DLL из stock
   этого пакета: это штатная пара WeHavePhones, совпавшая с присланной dxgi.dll.
3. В настройках тестового контейнера поставьте WINEDEBUG=-all.
   WINEDLLOVERRIDES оставьте d3d11,dxgi=n (прочие нужные записи не удаляйте).
4. Обычные локальные d3d11.dll и dxgi.dll рядом с EXE игры оставьте отключёнными,
   как в успешном запуске через system32. Не смешивайте ARM64 и ARM64EC пакеты.

## Каждый запуск
Откройте тестовый контейнер, затем двойным нажатием запустите play-custom.bat.
Путь уже настроен на D:\Wow test\World of Warcraft\_forever_\Wow-ARM64.exe.
При другом пути передайте его BAT-файлу первым аргументом в кавычках.

Программа проверит исходники и резервную копию, установит обе DLL в system32,
сверит SHA-256 и только после успеха запустит игру. Если запущен процесс Wow*,
файлы неизвестной версии или операция копирования не прошла, игра не запустится.
При ошибке копирования предусмотрен возврат уже изменённых файлов.
Проблему возврата программа покажет явно; снимки доступны в папке rollback.

Ожидаемый HUD: WOW-CUSTOM-ARM64-NATIVE [bcec80c1e075].
Версия DXVK остаётся прежней: новая здесь утилита установки, а не оптимизированные DLL.
Проверено на Windows CI: установка, повторная установка, откат, порча источника,
блокировка второй DLL и откат первой, неизвестная версия, отсутствие backup.
Windows CI не заменяет проверку ARM64-утилиты в Wine на планшете.

## Логи и откат
Логи DXVK будут рядом с утилитой в logs. Журнал Wine при -all сохраняется приложением
без подробной трассировки. Не включайте +loaddll,warn+seh для замеров FPS.
Для возврата штатной пары при закрытой игре запустите restore-stock.bat.
Для вывода текущих SHA-256: dxvk-test.exe status.

Если контейнер закрывается вместе с игрой, это не мешает: следующий запуск через
play-custom.bat снова установит нашу пару. Прямой запуск EXE этого не делает.
